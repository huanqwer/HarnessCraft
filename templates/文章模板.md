## 发布检查清单

1. 文件放进 `posts/`，文件名即文章标题（不按章节建子目录，保持平铺）。
2. 保留上面的头部 blockquote（作者简介）与 `[TOC]`，`---` 之后才是正文。
3. 在 `README.md` 的「系列文章」表格里登记一行：`| 序号 | [标题](posts/文件名.md) | 主题 |`，
   站点会按这张表的顺序生成系列导航。
4. 章节收尾用 `> 第X章毕`（X 为中文数字），非章节类文章可省略。
5. 本地自检：

   ```bash
   python3 tools/build_site.py --check --strict   # 内容体检
   python3 tools/build_site.py && mkdocs serve     # 本地预览 http://127.0.0.1:8000
   ```
